Pasos para conectar switch 2960 de Cisco:
1. Conectar cable de alimentación.
2. Ethernet (Console) y adaptador serial (USB).
3. En la terminal usar "sudo minicom -s". Entrar en "Serial port setup".
4. Configurar el dispositivo serial como "/dev/ttyUSB0" (A) y bits por segundo como "9600 8N1" (E). 
5. Guardar la configuración a por defecto.
6. Hacer "sudo minicom" para conectarse al switch. 
7. Esperar a que inicie.
8. Entrar en modo configuración: desconectar el cable de alimentación, mantener apretado el botón Mode y conectar el cable de alimentación de nuevo. Esperar un tiempo hasta acceder al menú de configuración.
9. Cuando cargue, usar flash_init.
10. Se puede usar dir para ver el directorio. Para ver el directorio de la memoria: "dir flash:".
11. Borrar los archivos de la configuración actual (delete config.text y delete vlan.dat).
12. Usar reload o boot para reiniciar el switch.
