Una vez reiniciado el switch, se realizó la siguiente configuración:

Entrar al modo privilegiado:
enable

Crear la VLAN 350 y asignarle nombre:
configure terminal
vlan 350
name G3E5
exit

Asignar los puertos Fa0/13 al Fa0/24 a la VLAN 350:
interface range fa0/13 - 24
switchport mode access
switchport access vlan 350
exit

Guardar la configuración:
end
write memory

Salida del comando show vlan brief

Switch# show vlan brief
